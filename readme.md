# PomaVPN — Android-клиент

Android-клиент для VPN-сервера [poma-vpn](https://github.com/khromenokroman/vpn) 0.5.0.0,
протокол **POM2**: UDP-туннель с шифрованием XChaCha20-Poly1305 (`libsodium`),
защитой от повторов (окно RFC 6479) и сессиями на основе времени запуска.

Серверная часть — отдельный проект на C++ (Linux). Формат пакета — копия
`src/share/{crypto,replay,packet}.*` сервера в `app/src/main/cpp/` (договор с сервером,
менять только вместе с сервером).

---

## Возможности

- VPN-туннель поверх UDP по протоколу POM2 (`Crypto`, `TxSession`, `PeerState`)
- Ключи направлений выводятся из общего секрета (`crypto_kdf`), пакет нельзя отразить отправителю
- Keep-alive каждые 10 с; keep-alive открывает сессию собеседника и обновляет адрес за NAT
- Обнаружение перезапуска сервера: туннель восстанавливается автоматически
- Контроль расхождения часов (допуск 60 с) и «сервер молчит 35 с»
- IPv6-трафик заворачивается в TUN (ULA-адрес и маршрут `::/0`) и там отбрасывается,
  а не идёт мимо туннеля
- Работа как **foreground service** с уведомлением («на орбите» / «стыковка...»)
- Интерфейс «полёт в космос»: звёздное поле с параллаксом, гиперпрыжком, туманностью
  и цветными звёздами, планета с кольцом, ракета (площадка → взлёт → орбита → посадка),
  телеметрия, обратный отсчёт 3-2-1, явная кнопка «ПУСК»/«ПОСАДКА» с пульсацией
- Состояния: `Готов к старту`, `Стыковка`, `На орбите`, `Нет связи с ЦУП`, `Авария`
- Телеметрия: отправлено/получено (Б/КБ/МБ/ГБ с десятичной запятой по локали),
  отброшено пакетов (повторы и чужие сессии)
- Ошибки стыковки видны: причина публикуется в `Авария`, VPN-интерфейс закрывается
  (таймаут стыковки 45 с, падение рабочего потока, старый протокол, расхождение часов)
- Настройки («Центр управления полётом»): сервер, порт, адрес в туннеле, ключ, MTU
- Проверка настроек до подключения (`ConfigValidator`, покрыт юнит-тестами)
- Ключ вводится как содержимое файла `/etc/poma-vpn/key` сервера; хвостовые пробелы
  и переводы строк отбрасываются как у сервера
- Учёт системной настройки «убрать анимацию» (`ANIMATOR_DURATION_SCALE = 0`)
- Отладочный автозапуск по extras активности — только в debug-сборке (`BuildConfig.DEBUG`)
- Сборка под `arm64-v8a`, `armeabi-v7a`, `x86`, `x86_64`

## Протокол POM2

Формат пакета (подробнее — readme сервера, раздел «Формат пакета»):

```
[magic "POM2" 4][начало сессии 8][случайная часть 8][номер 8][шифротекст + тег 16]
```

- nonce — 24 байта после magic, magic проверяется как associated data
- клиент шифрует ключом направления `CLIENT_TO_SERVER`, принимает в обратном
- keep-alive: `[0x00][0x01][0x00][0x00][IPv4 в туннеле 4][время, нс int64 BE]`, раз в 10 с
- сервер старой версии (magic «POMA») обнаруживается и сообщается пользователю

## Требования

- Android Studio (поддержка C++ / NDK)
- Android NDK (например `28.2.13676358`)
- CMake `3.22.1`
- Минимальный SDK: `24`, Android 7.0 (Nougat) и выше
- Сервер poma-vpn 0.5.0.0 (отдельный проект)

## Сборка

```bash
./gradlew --offline assembleDebug assembleRelease testDebugUnitTest
```

Перед сборкой Android-приложения нужно собрать `libsodium` под все нужные архитектуры:

```bash
cd third_party
./build-libsodium-android.sh
```

Результат — в `third_party/libsodium-android/<abi>/`.

## Проверка на эмуляторе

`tests/emulator_e2e.sh` поднимает сервер 0.5.0.0 в docker (`debian:trixie` + пакет релиза),
запускает headless-эмулятор `Pixel_6_Pro_13`, ставит debug-APK и проверяет:

- в logcat появляется «Туннель установлен»;
- `adb shell ping -c3 192.168.200.1` (сервер в туннеле) проходит;
- с неверным ключом туннель не устанавливается: по таймауту стыковки публикуется
  ERROR и VPN-интерфейс закрывается (`ip route` без `tun`);
- после `docker restart` сервера туннель восстанавливается не позже чем через 20 с;
- отключение и повторное подключение через `action=disconnect`/`action=connect`
  в уже запущенном процессе работает (pid процесса не меняется);
- после `docker pause`/`unpause` сервера `NO_RESPONSE` сменяется `EV_TUNNEL_RESTORED`
  и ping снова проходит;
- скриншоты состояний пишутся в `tasks/` основного репозитория.

Скрипт сам гасит эмулятор и контейнер в конце.

## Структура

- `app/src/main/cpp/` — нативная часть: `native-lib.cpp` (потоки, UDP, JNI),
  `crypto/replay/packet.*` — договор с сервером (не менять)
- `app/src/main/java/com/example/vpn/` — Kotlin: `MainActivity`, `MyVpnService`
  (VPN service, JNI-колбэки), `SpaceFlightView` (сцена на Canvas),
  `ConfigValidator`, `VpnConfig`, `VpnState`
- `app/src/test/` — юнит-тесты `ConfigValidatorTest`
